

# Enterprise Naming and Tagging Standard

## Purpose

This document defines the naming and tagging conventions used within the Enterprise Platform lab.

## Naming Convention

Pattern: <resource-type>-<application>-<environment>-<region>-<instance>

Example: aks-orders-dev-swc-001

## Tagging Standard

Environment = dev
Application = orders
Project = enterprise-platform
Owner = william
ManagedBy = manual
